How options are ranked

  1. Fewest cabinets.
  2. Symmetrical about the center line (21-24-24-21 beats 24-24-24-18).
  3. Sizes step up toward the center, so with an odd count the center box is the largest.
  4. Fillers closest to the minimum.
  5. Smallest spread between largest and smallest box, then fewest different sizes.
